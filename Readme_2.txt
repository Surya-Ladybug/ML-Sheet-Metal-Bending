PROFESSOR – HOW TO REVIEW (1 MINUTE)

This project is an ML-assisted digital twin for sheet metal bending,
trained on FEM simulation data.

No installation is required.

1. Open the provided web link
2. The application runs directly in the browser
3. Enter target angle and parameters
4. Review calculated geometry and visualizations

This deployment avoids local setup issues and ensures
identical results across all systems (Windows, macOS, Linux).
